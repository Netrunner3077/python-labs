# Лабораторная работа №3 · Вариант №6

Постройте таблицу значений функции и проверьте итог по всем подходящим точкам заданной сетки. Здесь собраны три решения этого варианта, их отчёты и проверки.

[Описание лабораторной](../../README.md) · [Репозиторий](../../../README.md) · [Задание DOCX](<docs/tasks/lab_03_v06_task.docx>)

## Условие и исходные данные

Табулировать функцию на отрезке **[-3; 3]** с шагом **.3**. Итог — **произведение** по значениям `y > 0`.

| Условие | Значение y |
| --- | --- |
| `x > 1` | `exp(x)` |
| `x < 0` | `2 * x - 1` |
| Остальные случаи | `-1` |

Точка сетки вычисляется как `a + i * h`, где `i` — целочисленный счётчик. Если правая граница не совпадает с точкой сетки, последняя строка остаётся внутри отрезка.

Начальное значение произведения — 1. Оно же остаётся итогом, если подходящих значений нет.

## Подготовка окружения

Для запуска нужен Python 3.10 или новее. Если окружение ещё не создано, выполните из корня проекта:

```powershell
python -m venv .venv
. .\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Для тестов выполните `python -m pip install -r requirements-dev.txt`.
[Установка на других системах](../../../README.md#установка).

## Запуск в PowerShell

Из корня проекта с активированной `.venv` перейдите в каталог варианта. Выберите команду нужного уровня.

```powershell
Set-Location "lab_03_loops/variants/v06"
python "src/tabulation_product_lab_03_v06_(noob).py"

python "src/tabulation_lab_03_v06_(basic).py"
python "src/tabulation_lab_03_v06_(advanced).py"
```

Путь к `result.txt` отсчитывается от текущего каталога терминала.

## Контрольные примеры

### noob

| Проверка и данные | Ожидаемый результат | Фактический результат |
| --- | --- | --- |
| x = −3 и x = 3 | Первая и последняя точки из 21 | 21 строка, обе границы на месте |
| x = −3, x = 0, x = 1.2 | y = −7, −1 и ≈ 3.320117 | −7.0, −1.0 и 3.3201169227365472 |
| Положительные y | 7 множителей. exp(14.7) ≈ 2421747.633 | 2421747.633252414 |

Положительные значения получены при x от 1.2 до 3 с шагом 0.3. Сумма этих аргументов равна 14.7, поэтому контрольное произведение равно exp(14.7).

| Итог по определённым значениям | 2421747.633252414 | Произведение = 2421747.633252414 |

## Автоматические тесты

Команда из корня репозитория с активированной `.venv`.

```powershell
python -m pytest "lab_03_loops/variants/v06/tests"
```

Проверки сверяют каждое x и y с контрольной сеткой и формулой, заново вычисляют итог и сопоставляют его с консольным и файловым выводом. Для нового `advanced` проверяются некратный шаг, неверные параметры и переопределённый путь результата.
