# Лабораторная работа №3 · Вариант №14

Постройте таблицу значений функции и проверьте итог по всем подходящим точкам заданной сетки. Здесь собраны три решения этого варианта, их отчёты и проверки.

## Условие и исходные данные

Табулировать функцию на отрезке **[-5; 5]** с шагом **.4**. Итог — **сумма** по значениям `y > 0`.

| Условие | Значение y |
| --- | --- |
| `x < 0` | `x ** 2 - 1` |
| `0 < x < 1.5` | `cos(x)` |
| `x > 1.5` | `sin(x - 1)` |

Точка сетки вычисляется как `a + i * h`, где `i` — целочисленный счётчик. В новом `noob` последняя строка остаётся внутри отрезка, если правая граница не совпадает с точкой сетки.

Если строгие условия оставляют точку без формулы, в новых решениях она отображается как «не определено» и исключается из итога. Старые `basic` и `advanced` v14 используют собственное граничное соглашение, описанное в отчётах.

## Подготовка окружения

Для запуска нужен Python 3.10 или новее. Если окружение ещё не создано, выполните из корня проекта:

```powershell
python -m venv .venv
. .\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Для тестов выполните `python -m pip install -r requirements-dev.txt`.
[Установка на других системах](../../../README.md#установка).

## Запуск в PowerShell

Из корня проекта с активированной `.venv` перейдите в каталог варианта. Выберите команду нужного уровня.

```powershell
Set-Location "lab_03_loops/variants/v14"
python "src/tabulation_lab_03_v14_(noob).py"

python "src/tabulation_sum_lab_03_v14_(basic).py"
python "src/tabulation_sum_lab_03_v14_(advanced).py"
```

Для штатной сетки в `basic` и `advanced` введите `-5`, `5`, `0.4` на отдельных строках.

## Контрольные примеры

### noob

| Проверка и вход | Ожидаемый результат | Фактический результат |
| --- | --- | --- |
| Сетка по условию | 26 точек, от -5 до 5 | 26 строк таблицы |
| Итог по определённым значениям | 112.68438917896029 | Сумма = 112.68438917896032 |

Использован Python float. Точки, для которых ветвь отсутствует, отмечаются в таблице и исключаются из итогового расчёта.

### basic

| Проверка и вход | Ожидаемый результат | Фактический результат |
| --- | --- | --- |
| a = −5, b = 5, h = 0.4 | 26 строк, S ≈ 112.684389 | 26 строк, S = 112.684389 |
| a = −1, b = 1.5, h = 0.5 | y(−1) = 0. Проверка соглашения о границах | y(0) = 1, y(1.5) = 0.479426, S = 2.897310 |
| a = 0, b = 1, h = 0.6 | Точки 0 и 0.6 | Дополнительно выведена точка 1.2 |
| h = 0, h < 0 или b < a | Отклонение входных данных | Сообщение и код завершения 1 |

Вычисления выполняются с Python float. Методические требования указывают одинарную точность. Для нецелого (b − a) / h округление числа шагов может вывести сетку за b.

### advanced

| Проверка и вход | Ожидаемый результат | Фактический результат |
| --- | --- | --- |
| a = −5, b = 5, h = 0.4 | 26 строк, S ≈ 112.684389 | 26 строк, S = 112.684389 |
| a = −1, b = 1.5, h = 0.5 | y(−1) = 0. Проверка соглашения о границах | y(0) = 1, y(1.5) = 0.479426, S = 2.897310 |
| a = 0, b = 1, h = 0.6 | Точки 0 и 0.6 | Дополнительно выведена точка 1.2 |
| h = 0, h < 0 или b < a | Отклонение входных данных | Исключение ValueError |

## Автоматические тесты

Команда из корня репозитория с активированной `.venv`.

```powershell
python -m pytest "lab_03_loops/variants/v14/tests"
```

Проверки сверяют каждое x и y с контрольной сеткой и формулой, заново вычисляют итог и сопоставляют его с консольным и файловым выводом. Для нового `advanced` проверяются некратный шаг, неверные параметры и переопределённый путь результата.

[Код тестов](<tests/test_solutions.py>)

В старых решениях варианта №14 ожидаемые отказы фиксируют выход последней точки за границу при некратном шаге. Отдельные тесты сохраняют проверку существующего поведения при x = 0 и x = 1.5.

## Как предложить изменение

Добавьте контрольный пример в `tests/test_solutions.py` нужного варианта, если меняете его поведение.
Проверьте изменение командой `python -m pytest lab_03_loops/variants/v14/tests` из корня проекта и приложите итог прогона к запросу на изменение.
