# Лабораторная работа №3 · Вариант №4

Постройте таблицу значений функции и проверьте итог по всем подходящим точкам заданной сетки. Здесь собраны три решения этого варианта, их отчёты и проверки.

[Описание лабораторной](../../README.md) · [Репозиторий](../../../README.md) · [Задание DOCX](<docs/tasks/lab_03_v04_task.docx>)

## Условие и исходные данные

Табулировать функцию на отрезке **[-pi; pi]** с шагом **pi/8**. Итог — **сумма** по значениям `y > 0`.

| Условие | Значение y |
| --- | --- |
| Все точки | `1 / (x + 2 * pi) - sin(x)` |

Точка сетки вычисляется как `a + i * h`, где `i` — целочисленный счётчик. Если правая граница не совпадает с точкой сетки, последняя строка остаётся внутри отрезка.

## Подготовка окружения

Для запуска нужен Python 3.10 или новее. Если окружение ещё не создано, выполните из корня проекта:

```powershell
python -m venv .venv
. .\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Для тестов выполните `python -m pip install -r requirements-dev.txt`.
[Установка на других системах](../../../README.md#установка).

## Запуск в PowerShell

Из корня проекта с активированной `.venv` перейдите в каталог варианта. Выберите команду нужного уровня.

```powershell
Set-Location "lab_03_loops/variants/v04"
python "src/tabulation_lab_03_v04_(noob).py"

python "src/tabulation_lab_03_v04_(basic).py"
python "src/tabulation_lab_03_v04_(advanced).py"
```

Путь к `result.txt` отсчитывается от текущего каталога терминала.

## Автоматические тесты

Команда из корня репозитория с активированной `.venv`.

```powershell
python -m pytest "lab_03_loops/variants/v04/tests"
```

Проверки сверяют каждое x и y с контрольной сеткой и формулой, заново вычисляют итог и сопоставляют его с консольным и файловым выводом. Для нового `advanced` проверяются некратный шаг, неверные параметры и переопределённый путь результата.

[Код тестов](<tests/test_solutions.py>)
