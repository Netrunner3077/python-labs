# Лабораторная работа №1 · Вариант №27

Вычислите выражение для заданных x и y и сверьте округлённое значение и целую часть с контрольным примером. Здесь собраны три решения этого варианта, их отчёты и проверки.

[Описание лабораторной](../../README.md) · [Репозиторий](../../../README.md) · [Задание DOCX](<docs/tasks/lab_01_v27_task.docx>)

## Условие и исходные данные

Вычислить выражение по строке варианта из преподавательской таблицы. Получить округлённое значение и целую часть исходного результата.

```python
(sqrt(abs(x ** 3 - 3.4e-3 * y)) + x ** 2 * y) / (3 * cos(x * y))
```

| x | y | Ответ в таблице |
| --- | --- | --- |
| 12.615 | 7.5 | 441.8435 |

Тригонометрические аргументы измеряются в радианах. `log` обозначает натуральный логарифм, `log10` — десятичный. Целая часть отсекается по направлению к нулю.

## Подготовка окружения

Для запуска нужен Python 3.10 или новее. Если окружение ещё не создано, выполните из корня проекта:

```powershell
python -m venv .venv
. .\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Для тестов выполните `python -m pip install -r requirements-dev.txt`.
[Установка на других системах](../../../README.md#установка).

## Запуск в PowerShell

Из корня проекта с активированной `.venv` перейдите в каталог варианта. Выберите команду нужного уровня.

```powershell
Set-Location "lab_01_linear_function/variants/v27"
python "src/linear_lab_01_v27_(noob).py"

Set-Content -LiteralPath input.txt -Value @('12.615', '7.5') -Encoding ascii

python "src/linear_lab_01_v27_(basic).py"
python "src/linear_lab_01_v27_(advanced).py"
```

Пути к `input.txt` и `result.txt` отсчитываются от текущего каталога терминала.

## Автоматические тесты

Команда из корня репозитория с активированной `.venv`.

```powershell
python -m pytest "lab_01_linear_function/variants/v27/tests"
```

Проверки запускают все три скрипта в изолированных каталогах. Для расчёта проверяются контрольные и альтернативные x и y, округление и целая часть. Для файловых решений проверяются десятичная запятая, запись результата, а для нового `advanced` также пользовательские пути и ошибка ввода. Отдельная проверка анализирует синтаксис `noob` и исключает пользовательские функции, форматирование и файловый ввод.
