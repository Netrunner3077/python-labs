# Лабораторная работа №4 · Вариант №5

Выведите исходную матрицу и проверьте результат отбора или обработки её строк, столбцов и элементов. Здесь собраны три решения этого варианта, их отчёты и проверки.

[Описание лабораторной](../../README.md) · [Репозиторий](../../../README.md) · [Задание DOCX](<docs/tasks/lab_04_v05_task.docx>)

## Условие и исходные данные

Исходный список содержит **72** целых значений из диапазона **[-20; 80]**. Его печатают в виде матрицы **8 × 9**.

**Задание.** Определить минимальный элемент каждой строки массива и его координаты.

Обойти строки, найти наименьшее значение в каждой и определить его строку и столбец.

Линейный индекс элемента строки `i` и столбца `j` равен `i * m + j`.

В преобразованной матрице каждая строка представляет вычисленные характеристики исходной строки или столбца.

Координаты нумеруются с единицы. При равенстве выбирается первое вхождение.

## Подготовка окружения

Для запуска нужен Python 3.10 или новее. Если окружение ещё не создано, выполните из корня проекта:

```powershell
python -m venv .venv
. .\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Для тестов выполните `python -m pip install -r requirements-dev.txt`.
[Установка на других системах](../../../README.md#установка).

## Запуск в PowerShell

Из корня проекта с активированной `.venv` перейдите в каталог варианта. Выберите команду нужного уровня.

```powershell
Set-Location "lab_04_arrays/variants/v05"
python "src/array_lab_04_v05_(noob).py"

python "src/array_lab_04_v05_(basic).py"
python "src/array_lab_04_v05_(advanced).py"
```

Путь к `result.txt` отсчитывается от текущего каталога терминала.

## Автоматические тесты

Команда из корня репозитория с активированной `.venv`.

```powershell
python -m pytest "lab_04_arrays/variants/v05/tests"
```

Тесты проверяют размеры и диапазон, пересчитывают преобразованную матрицу и результат по напечатанным значениям. В новых решениях дополнительно подаются фиксированные массивы с границами и нулями. У нового `advanced` проверяется воспроизводимость по seed и отдельный выходной файл.
