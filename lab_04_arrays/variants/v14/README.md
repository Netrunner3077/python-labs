# Лабораторная работа №4 · Вариант №14

Выведите исходную матрицу и проверьте результат отбора или обработки её строк, столбцов и элементов. Здесь собраны три решения этого варианта, их отчёты и проверки.

[Описание лабораторной](../../README.md) · [Репозиторий](../../../README.md) · [Задание DOCX](<docs/tasks/python_04_lab.docx>)

## Условие и исходные данные

Исходный список содержит **90** целых значений из диапазона **[-50; 20]**. Его печатают в виде матрицы **10 × 9**.

**Задание.** Определить номера положительных элементов массива.

Пройти плоский список и вывести порядковые номера элементов больше нуля.

Линейный индекс элемента строки `i` и столбца `j` равен `i * m + j`.

В новом решении `noob` преобразованная матрица сохраняет положительные значения и заменяет остальные нулями. В старых решениях `basic` и `advanced` после исходной матрицы выводится список найденных номеров.

Номера элементов плоского массива отсчитываются с единицы.

## Подготовка окружения

Для запуска нужен Python 3.10 или новее. Если окружение ещё не создано, выполните из корня проекта:

```powershell
python -m venv .venv
. .\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Для тестов выполните `python -m pip install -r requirements-dev.txt`.
[Установка на других системах](../../../README.md#установка).

## Запуск в PowerShell

Из корня проекта с активированной `.venv` перейдите в каталог варианта. Выберите команду нужного уровня.

```powershell
Set-Location "lab_04_arrays/variants/v14"
python "src/array_lab_04_v14_(noob).py"

python "src/array_positive_indices_lab_04_v14_(basic).py"
python "src/array_positive_indices_lab_04_v14_(advanced).py"
```

Для параметров варианта в `advanced` нажмите Enter пять раз.

### noob

| Проверка и вход | Ожидаемый результат | Фактический результат |
| --- | --- | --- |
| Размер и диапазон | 10 × 9, 90 элементов от -50 до 20 | 10 × 9, диапазон проверен |
| Результат по напечатанному массиву | Независимый пересчёт по исходной матрице | [2, 8, 10, 20, 23, 35, 36, 42, 43, 46, 48, 50, 60, 62, 64, 65, 67, 69, 71, 72, 73, 74, 77, 80, 81, 84, 86 […] |

В преобразованной матрице сохранены отобранные значения. Остальные позиции заполнены нулями. Номера элементов плоского массива отсчитываются с единицы.

### basic

| Проверка и вход | Ожидаемый результат | Фактический результат |
| --- | --- | --- |
| Параметры варианта 90 / −50 / 20 / 10 / 9 | 10 строк по 9 значений; все числа в [−50; 20] | 10 × 9; min = -49; max = 20 |
| Проверка по напечатанной матрице | 29 положительных; № 2 = 17, № 8 = 7, № 10 = 9 | 29 положительных; № 2 = 17, № 8 = 7, № 10 = 9 |
| Нулевые значения при seed = 14 | Нули не попадают в список | B[10], B[11], B[77] пропущены |

Общая часть задания требует отдельной функции и вывода преобразованной матрицы. Вариант 14 определяет поиск номеров и не задаёт правила преобразования. Поэтому на выходе показаны исходная матрица и найденные номера. В базовом скрипте генерация выполнена в основном теле программы.

Общая часть задания требует отдельной функции и вывода преобразованной матрицы. Вариант 14 определяет поиск номеров и не задаёт правила преобразования. Поэтому на выходе показаны исходная матрица и найденные номера.

## Автоматические тесты


Тесты проверяют размеры и диапазон, пересчитывают преобразованную матрицу и результат по напечатанным значениям. В новых решениях дополнительно подаются фиксированные массивы с границами и нулями. У нового `advanced` проверяется воспроизводимость по seed и отдельный выходной файл.
