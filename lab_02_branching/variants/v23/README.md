# Лабораторная работа №2 · Вариант №23

Запустите кусочную функцию на контрольных наборах и сравните результат для каждой ветви и её границ. Здесь собраны три решения этого варианта, их отчёты и проверки.

[Описание лабораторной](../../README.md) · [Репозиторий](../../../README.md) · [Задание DOCX](<docs/tasks/lab_02_v23_task.docx>)

## Условие и исходные данные

Вычислить кусочно заданную функцию. Входные величины передаются в порядке `x`, `y`, `c`, `d`.

| Условие | Выражение |
| --- | --- |
| `x * y > 3` | `x ** 3 + log10(x * y) ** (c * d)` |
| `2 < x * y < 3` | `3 * min(x, y, max(c * x, d * y))` |
| `x * y < 2` | `2 ** (c * d) - x` |

При `x * y = 2` и `x * y = 3` в исходной таблице нет формулы. Программа сообщает об отсутствии значения.

Условия проверяются сверху вниз. Вычисляется только выражение выбранной ветви. Для проверки удобно менять по одному параметру и отдельно подставлять значения на границах.

## Подготовка окружения

Для запуска нужен Python 3.10 или новее. Если окружение ещё не создано, выполните из корня проекта:

```powershell
python -m venv .venv
. .\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Для тестов выполните `python -m pip install -r requirements-dev.txt`.
[Установка на других системах](../../../README.md#установка).

## Запуск в PowerShell

Из корня проекта с активированной `.venv` перейдите в каталог варианта. Выберите команду нужного уровня.

```powershell
Set-Location "lab_02_branching/variants/v23"
python "src/branching_lab_02_v23_(noob).py"

python "src/branching_lab_02_v23_(basic).py"
python "src/branching_lab_02_v23_(advanced).py"
```

Контрольный ввод для `basic` и `advanced` в порядке запросов: `x = 2`, `y = 2`, `c = 1`, `d = 2`. Путь к `result.txt` отсчитывается от текущего каталога терминала.

## Автоматические тесты

Команда из корня репозитория с активированной `.venv`.

```powershell
python -m pytest "lab_02_branching/variants/v23/tests"
```

Проверки прогоняют наборы для всех ветвей и строгих границ, сравнивают исходные величины и численный результат. Для `noob` значения меняются только во временной копии. Для `basic` и `advanced` сверяется файл результата. Дополнительная проверка подаёт `advanced` нечисловой ввод и проверяет повторный запрос.

[Код тестов](<tests/test_solutions.py>)
