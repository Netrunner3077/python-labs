# Учебные материалы Python Labs

Здесь хранится общая вводная методичка. Задания, отчёты и блок-схемы привязаны к конкретной лабораторной и варианту.

## Вводная методичка

[Introduction to Python (PDF)](introduction_to_python.pdf) знакомит со средой IDLE, операторами, переменными и типами, встроенными функциями, преобразованием данных и модулем `math`. В конце есть самостоятельные задания и контрольные вопросы.

PDF можно открыть в браузере или программе для просмотра PDF. Для чтения устанавливать Python не нужно.
